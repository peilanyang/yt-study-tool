產生逐字稿

  1. 步驟 1 取得字幕
  2. →
  3. 步驟 2 交給 Claude 整理
  4. →
  5. 步驟 3 貼回結果
  6. 依序完成，共 3 步

步驟 1：取得字幕

在 YouTube 影片下方說明欄按「…更多」→「顯示轉錄稿」，全選複製後貼到下面（含時間）；或上傳 .srt / .vtt 字幕檔。之後的版本會由 Windows 小程式自動取得。

步驟 2：交給 Claude 整理

按下面的按鈕複製提示詞，貼到 Claude 對話送出。Claude 會加上標點、分段、標出講者與時間。字幕很長時會分成幾份，請依序處理。

步驟 3：貼回 Claude 的回覆

翻譯成中文
